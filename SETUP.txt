=====================================
  HUMAN DETECTION PROTOTYPE - SETUP
=====================================

1. CREATE VIRTUAL ENVIRONMENT
   python -m venv venv311

2. ACTIVATE VENV
   venv311\Scripts\activate

3. INSTALL PACKAGES
   pip install -r requirements.txt

4. RUN THE PROGRAM
   python main.py

=====================================
  NOTES
=====================================

- Uses built-in laptop camera (index 0)
- Press Q in the detection window to quit
- Dashboard runs at http://localhost:5000
